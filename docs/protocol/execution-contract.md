# 统一安全执行约束

<!-- doc-role: reference -->

本文描述跨协议必须维护的执行约束。职责归属见[架构说明](../architecture/README.md)，具体行为需结合源码与相关回归验证；不代表所有部署环境已经验收。

下列阶段、关联标识和错误名称表示职责与语义，不要求新建通用执行框架、第二套身份/授权模型或统一大上下文。优先复用现有 Contracts、Protocol Core 与 Security Core；仅为实际调用补充必要接口，并保留配置兼容。

## 执行阶段与职责

```text
有界解析 / 协议识别 / 可信身份
               ↓
操作归一化与稳定关联
               ↓
候选预筛（可选，不产生执行许可）
               ↓
业务授权 + 专项控制 + 有界资源准入
               ↓
最终目标、继承策略、上下文与凭据检查
               ↓
必要的审计持久化确认 → dispatch
               ↓
响应验证 / 持续校验 / 提交状态 / 释放租约
```

这是职责顺序，不要求所有协议共用单一线性函数。例如工具审批必须绑定最终参数与目标，能力签发不能早于授权；下载、反向请求和 sampling 会创建子操作，需重新经过对应检查。

## C01 可信身份

- User/Agent/Tenant/Client/Delegation 只来自已验证认证结果或可信宿主注入；消息体和任意 header 不构成身份。
- normalize 层不得将缺失认证包装成“已验证的空身份”。公开发现与匿名操作必须由显式策略决定。
- 会话、Task、Context 归属绑定 issuer 和主体，必要时包含 Client/Session；令牌更新是否允许保持绑定须明确定义。
- 长操作保存的是可重新验证的绑定，不将创建时 Allow 当作永久凭据。

## C02 请求与执行关联

区分四种标识：

| 标识 | 来源 | 用途 |
| --- | --- | --- |
| 内部 request ID | Gateway 生成 | 同一次入口处理、授权与审计关联；同一请求的重试保持稳定 |
| wire RPC ID / 客户端 correlation ID | 调用者输入 | 原协议响应配对或检索辅助；有界保存，不证明权限/唯一性 |
| operation ID / parent ID | Gateway 生成或可信执行账本 | 关联独立子操作、任务与反向调用 |
| attempt | Gateway 维护 | 区分重试/降级尝试，不改变业务授权范围 |

同一 session 内多个 RPC、扇出子请求、采样产生的模型调用需能区分。客户端重连是新的入口请求；通过受控 Task/Context 绑定恢复业务关联，不假定 request ID 跨连接不变。

兼容迁移：保留原 wire ID 返回语义；先增加内部关联，不直接把原客户端 ID 当作可信内部 ID。capability 的 request 绑定和后端消费必须同时迁移。

## C03 有界解析与操作分类

- 在授权前校验媒体类型、消息大小、envelope、版本、ID 形状和方法所需字段；错误输入不得转成可匹配宽泛 Allow 的虚构方法。
- 每种消息方向、binding、版本分别声明 supported、explicitly unsupported、extension；发现能力不得超出可执行能力。
- Enforce 中未知操作先拒绝再转发；观察模式可保留原行为，但必须记录拒绝原因。解析损坏无需强行继续转发。
- SDK 反序列化不能静默丢弃安全相关参数；保留字段必须继续遵守有界校验。

## C04 Action 与资源标识

- Action 表示业务操作，Resource 使用稳定且无歧义的可信命名空间；实际网络目标另有最终出口检查。
- MCP 对象须明确 server 作用域；同名工具跨 server 是否共享权限必须明确。现有 ToolInvoke/Capability 仍有 `Tool(tool_name)` 的兼容语义，不能在组件迁移时悄悄改为 server-scoped ID。若后续调整权限标识，须单独设计版本/映射、消费者迁移与默认拒绝边界；当前组件化不擅自变更该契约。
- 读 Task、读 Artifact、下载 Artifact、收 Push、恢复事件、调用模型互不隐含授予。
- LLM 输出的 tool call 是建议；必须在真实执行入口重新授权。

## C05 候选、授权与最终出口

- prefilter 只筛除不可能允许的候选，不调用审批、不签发 capability、不承诺上游执行。
- 业务授权在动作与参数确定后执行；实际目标确定后检查出口，目标变化重新检查。
- 父路由、子 backend、legacy 与当前安全配置的必要约束取交集，不得由下层覆盖上层。
- “只检查一次”限定于同一次相同边界检查；生命周期内身份、参数、目标或策略变化时必须重新检查。

## C06 参数、审批与一次性凭据

- 审批与 capability 绑定将要执行的动作、主体、资源和最终参数摘要。
- 客户端伪造的 capability/context/operation header 不得获得信任；只转发本次可信流程生成的材料。
- 补充 elicitation、工具参数转换或重写后不得复用不覆盖新参数的原审批。
- capability 消费与实际业务幂等是不同问题；网络结果不确定时，不自动重新签发并重放副作用。

## C07 重试、降级与扇出

- 记录 attempt、目标、授权结果和执行结果；同一入口的 request ID 保持稳定。
- 授权拒绝、过期、归属失败不能以重试到其他目标绕过。
- 有副作用操作默认不自动重放；只有可信后端幂等契约与操作账本可明确放开。
- MCP 列表扇出逐个目标授权；部分失败策略只处理后端可用性，不能使拒绝目标的对象重新可见。
- 超时/断连后状态不确定应标为不确定，不等同于未执行或已取消。

## C08 流、通知与取消

- 连接握手权限不自动覆盖后续消息；订阅通知必须来自有效的授权订阅，反向请求必须绑定 live parent/pending request。
- 保护路径明确身份到期、配置失效、上下文撤销的复查频率，并在发送更多数据前执行相应校验。
- 内容窗口已输出部分无法撤回；阻断必须终止或按协议发出错误，不能伪装成正常完成。
- 客户端取消/断连触发本地资源回收；尽可能向上游传播取消，但不承诺外部副作用回滚。
- 取消与迟到 ACK/响应竞争时，旧响应不能重建已失效许可。

## C09 状态提交、恢复与撤销

- 区分 admission、dispatched、结果未知、结果确认；任务状态只按验证后的响应/事件转换。
- 状态提交与资源释放要处理错误及取消路径；持久化失败不能返回虚假的恢复保证。
- 恢复重新验证当前身份、Owner、策略/配置、文档版本和 cursor 绑定，不自动重放外部调用。
- MCP session replay、MCP 异步任务恢复、A2A 本地事件恢复是三种不同能力；分别声明支持与存储边界。
- 过期或被撤销上下文不得通过重签发、重连或降低分级重新获得权限。

## C10 审计语义

- 事件至少可关联内部 request/operation/attempt、操作、资源、阶段、决策与稳定原因码；敏感内容和凭据不进入事件。
- 区分 candidate、authorization、dispatch、execution outcome；Allow 不表示已发送或执行成功。
- 必须持久化的准入事件在实际副作用前取得确认。完整记录 Deny/错误的持久化要求单独规定，不能从当前 requiredAudit 推断。
- 审计失败后的响应取决于声明的强制审计策略；一般观测投影不是权威执行账本。

## C11 错误映射

内部至少区分：Malformed、Unsupported、Unauthenticated、Denied、OwnershipMismatch、ExpiredOrRevoked、BudgetExhausted、DependencyUnavailable、OutcomeUnknown。

每个适配器映射为自身 HTTP/JSON-RPC/流式响应；通知不能伪造请求 ID，响应开始后不能再改 HTTP status。对外隐藏对象是否存在的策略可保留，内部仍保留稳定分类；默认不返回原始凭据、配置路径或详细规则表达式。

## C12 模式、组合与资源约束

- 显式记录 Audit/Shadow/Enforce 与启用的专项控制；只声明当前组合真正可执行的协议能力。
- 无法执行保护契约的组合在启动/加载时拒绝；不得静默退回普通透传。
- 有界限制包括消息、事件、并发、pending、任务、订阅、缓存、流时长和持久化容量。
- 错误、取消、超时、配置更新后应释放本地租约；必须为安全拒绝导致的资源释放保留测试。

## 接口落地边界

已有 `gateway-contracts` 的配置生命周期、`gateway-protocol-core` 的绑定执行契约和现有 `security-*` 是落地基础。协议专用接口优先归本协议组件，Host 注入完整受保护操作；绑定 HTTP 基础调用本身不代表 Tool 授权。协议 parser/state machine 归组件，统一安全内核接收可信事实，Host 负责装配与最终执行，不通过 Service Locator 或原始连接暴露绕过检查的路径。

重构不得在没有兼容说明与相关回归的情况下同时改变协议行为、策略 ID 语义和存储格式。代码与测试按实际迁移风险验收，本契约不新增自动审批、暂停或部署流程。
